# Changelog

## 0.1.0a1 — 2026-10-14

Initial alpha: strict local model, typed control/network graph, 32 evidence-aware rules, 10 official source references, five synthetic/blank inputs, safe HTML/JSON/CSV reports, scope-aware comparison, CLI, loopback form, tests and release documentation.

Within the initial build, regression tests caught and fixed mutable report snapshots and a false conflation of control with network reachability. Advanced JSON imports preserve duplicate-key rejection, and in-flight UI evaluations are discarded when inputs change.

Not yet provided: cloud collectors, automatic infrastructure construction or restoration, threat scanning, evidence verification, BreakGlassMap interoperability, a published package/repository, or independent security review.
